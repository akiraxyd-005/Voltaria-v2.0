## 🚀 Deployment

### Deploy on Railway

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/template/your-template-link)

### Local Installation

```bash
git clone https://github.com/Arashi005/Voltaria-v2.0
cd Voltaria-v2.0
npm install
npm start
```

Scan the QR code via WhatsApp → Settings → Linked Devices → Link a Device.
